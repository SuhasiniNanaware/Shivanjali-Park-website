# 🌳 Shivanjali Park - Real Estate Website

Official website for **Shivanjali Park Farmhouse Plots** by **Brahmandnayak Developers**.

## 📖 Project Overview

Shivanjali Park is a farmhouse plotting project located at Alandi Mhatoba, Pune. This website was developed to provide visitors with project information, location details, gallery images, amenities, and an inquiry system connected to a cloud database.

The project serves as both a real business website and a software engineering portfolio project.
